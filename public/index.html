Model Bazlı Otomatik Mod Eşleme (Auto-Modes)

Belirli bir model yüklendiğinde otomatik olarak hangi modların açılacağını belirleyin. Örneğin 3B modellerde LPM modları otomatik açılabilir, büyük modellerde HPM veya Derin Düşünme devreye girebilir.

Çalışma Modları Kılavuzu & Açıklamalar
LPM (Low Parameter Mode)

Küçük modeller (1B-7B) tüm araçları aynı anda gördüğünde bozuk JSON üretebilir. LPM, araçları küçük gruplar halinde tek tek sorarak ("bu araç gerekli mi?") sadece gereken araçları prompta ekler. Küçük modellerde kesinlikle AÇIK olmalıdır.

LPM OM (Low Parameter Mod Odak Modu)

LPM araç elemesine başlamadan önce modele "Kafanda nasıl bir araç kullanmak var?" diye sorar ve ihtiyacı netleştirir. 3B modellerin hedeften sapmaması için LPM ile birlikte AÇIK tutulması önerilir.

HPM (High Parameter Mode)

LPM'nin tam tersidir. 14b ve fazlası parametreli modellerde gereksiz api çağırmayı ve yavaşlamasını önler. Bu gibi büyük parametreli modeller işini LPM olmadan daha iyi yapıcağı kesindir.

Derin Düşünme (Advanced Reasoning)

Ajanı iki aşamalı çalıştırır: Önce bir Mimar (Planner) gibi düşünüp işi planlar, araç çalıştıktan sonra Kalite Kontrolcü (QA Checker) gibi sonucu denetler. Karmaşık kodlama ve hata ayıklamada AÇIK önerilir.

Görev Planı (Force Task Plan)

Ajanın körlemesine işlem yapmasını engeller; zorunlu olarak önce task_plan aracını çağırıp ekranda yapılacaklar listesi (Checklist) oluşturmasını sağlar. Adım adım takip için AÇIK tutulabilir.

SiMBA (Hafıza & Geçmiş Tecrübe)

Ajanın uzun vadeli hafızasını (memory.json) tarar; benzer geçmiş görevleri, yapılan düzeltmeleri ve tecrübeleri modele enjekte eder. Geçmişi hatırlaması için AÇIK tutulmalıdır.

Local AI Computer-Use Agent Documentation

How to run LM Studio for the Agent

  1. Download and open LM Studio.
  2. Download a code-instruct model like Qwen/Qwen2.5-Coder-7B-Instruct or meta-llama/Llama-3-8B-Instruct.
  3. Go to the Developer / Server tab (left sidebar symbol with double brackets ``).
  4. Select the loaded model at the top.
  5. Ensure the local server port is set to `1234` and click Start Server.
  6. Type your task in the chat window of this browser agent!

Security Rules

  • Strict Sandbox Confirmation: The local server runs command prompts and interacts with files. However, it will never perform any task until you click the Approve Action button.
  • Command Editing: If you see the agent write an argument incorrectly or try to add something you do not want, you can edit the arguments inside the text editor box on the approval screen before approving it.
  • Command Blacklisting: The safety filter runs commands against a regex validator to lock down critical directories and destructive procedures (such as deleting system databases).
