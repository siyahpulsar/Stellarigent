# Obsidian Note Management Guide

Rules for editing Obsidian vaults.

## Note Linking Syntax
- Standard link: `[[Note Name]]`
- Backlink with custom label: `[[Note Name|Custom Label]]`
- Tags: `#tag-name`

## Daily Notes Structure
- Title: `YYYY-MM-DD`
- Sections:
  - `## Tasks Checklist`
  - `## Accomplishments`
  - `## Technical Notes`
