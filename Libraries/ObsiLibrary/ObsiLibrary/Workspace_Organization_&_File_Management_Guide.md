# Workspace Organization & File Management Guide

Rules for maintaining a clean, structured directory layout.

## Core Directives
- **Zero Root Pollution**: Never create or download files directly in the project root directory.
- **ObsiLibrary Storage**: All downloaded files, images, generated content, and guides must reside under `ObsiLibrary/`.

## Folder Hierarchy
- **Guides & Rules**: Save under `ObsiLibrary/ObsiLibrary/` (e.g., `rehber.md`, `obsidian_guide.md`, `web_search_guide.md`).
- **Visuals & Images**: Save under `ObsiLibrary/Images/` (e.g., save any downloaded images or graphics inside this folder).
- **Research & Text**: Save under `ObsiLibrary/Research/` or `ObsiLibrary/Topics/` in organized subdirectories depending on the subject.
- **Media & Downloads**: Save under `ObsiLibrary/Downloads/` (e.g., audio files, videos, documents).

## Clean-Up Rules
- **Temporary Files**: Delete scratch files or temporary scripts immediately after verification.
- **Duplicates**: Check if a similar file or directory already exists before downloading or creating a new one.
