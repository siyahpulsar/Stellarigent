# Image Download & Vision Analysis Guide

Rules for downloading images and utilizing vision capabilities.

## Key Actions

- **Finding Image URLs**:
  - Always view the target page (e.g. search page or gallery site) using the `view_website` tool.
  - Scan the `=== IMAGES FOUND ON PAGE ===` section in the tool output.
  - Locate direct links to images (URLs ending in `.jpg`, `.png`, `.jpeg`, `.webp` or defined as `[Image alt="..." src="..."]`).
  - If the `src` attribute is a relative path (e.g., `/images/apple.jpg`), resolve it against the website's base domain (e.g., `https://pixabay.com/images/apple.jpg`) before passing it to `download_image`.

- **Download an Image Locally**:
  - Use the `download_image` tool structure:
  ```json
  {
    "action": "download_image",
    "url": "IMAGE_URL",
    "path": "save_directory/filename.extension",
    "explanation": "Why this image is needed"
  }
  ```

## Vision Capability & Image Analysis

- If vision capability is verified at startup (`canAnalyzeImages` is true), any image generated by `download_image` or `take_screenshot` is automatically converted to base64 and sent to you in the next message context.
- **Visual Validation Rule**:
  - When you successfully download an image, the system will automatically attach the image to your next thinking step.
  - **You MUST visually inspect this attached image** to verify that it matches the user's intent (e.g., verifying it is indeed a high-quality apple, not a logo, a placeholder, or a broken icon) before concluding the task.
  - If the image is incorrect or broken, locate a different image URL and repeat the download. Only conclude the task when the image content is verified as correct.
